Overview:
This project investigates whether neural oscillatory interactions, quantified through Phase-Amplitude Coupling (PAC), can be used to decode cognitive states from electroencephalography (EEG) recordings.

PAC features are extracted from event-related EEG epochs and used to train a Random Forest classifier capable of distinguishing between different cognitive conditions based on underlying patterns of neural activity. The project combines neuroscience signal processing techniques with machine learning to explore how brain activity can be translated into predictive models.

Research Question:
Can Phase-Amplitude Coupling (PAC) features extracted from EEG recordings be used to accurately classify cognitive states associated with attentional performance?

Data Description: 
The dataset consists of EEG recordings collected during the Sustained Attention to Response Task (SART), a widely used paradigm for measuring sustained attention and response inhibition. During the task, participants are presented with a sequence of numbers (1–9) and are instructed to respond to every stimulus except a designated target number (3). Behavioural markers such as errors on target trials are used to identify differences in attentional state and cognitive control.

Methodology:
1. EEG Data Import and Event Extraction: Event latencies and event labels were extracted and converted into an MNE-compatible event structure, where each event contained the sample index, event identifier and event type label, which was later used for epoch segmentation and trial classification.
2. EEG Data Conversion and Channel Configuration: Raw EEG signals were converted from microvolts to volts and imported into the MNE-Python framework as a continuous EEG recording. Channel names were extracted from the dataset metadata and used to create an MNE information object containing EEG channel labels, sampling frequency, and channel type information. Electrode locations were assigned using the International 10–20 electrode placement system through the standard_1020 montage.
3. Signal Filtering: To reduce high-frequency noise while preserving task-relevant neural activity, a low-pass filter with a cutoff frequency of 40 Hz was applied to the continuous EEG recording. Because the dataset had already undergone high-pass filtering at 1 Hz during acquisition or previous preprocessing, no additional low-frequency filtering was performed. To remove electrical interference from power-line noise, a notch filter centred at 60 Hz was applied to all channels.
4. Independent Component Analysis (ICA): Independent Component Analysis (ICA) was used to identify and remove physiological artifacts from the EEG recordings. ICA was performed using a variance retention threshold of 99%, a random seed of 97 and an automatic convergence criteria. The resulting independent components were inspected using an automated electrooculogram (EOG) detection procedure based on the Fp1 electrode. Components exhibiting strong correlations with ocular activity were identified as eye-blink or eye-movement artifacts and marked for removal.
5. Event Epoching: The continuous EEG recordings were segmented into event-related epochs using the extracted experimental event markers. Each epoch consisted of 200 ms before the event onset and 1000 ms after the event onset. This epoch window was selected to capture neural activity occurring immediately before and after task-relevant events. Epochs were grouped according to their associated event labels (missed targets to correct non-targets) and used as the input samples for subsequent feature extraction.
6. PAC Feature Extraction: Phase-Amplitude Coupling (PAC) was computed for each EEG epoch to quantify interactions between neural oscillations across frequency bands. For each epoch, the EEG signal was filtered into low-frequency bands: Theta (4-8 Hz) and Alpha (8-12 Hz). The EEG signal was also filtered into high-frequency bands: Beta (13-30 Hz) and Gamma (30-40 Hz). PAC values were calculated for each low-frequency/high-frequency band pair, producing a measure of how strongly the phase of slower oscillations modulated the amplitude of faster oscillations. The resulting PAC values served as quantitative descriptors of cross-frequency neural interactions during each cognitive event.
7. Feature Matrix Construction: A feature matrix was constructed by combining PAC features and spectral power measurements extracted from each EEG epoch. For each epoch, PAC values quantified cross-frequency coupling between low-frequency phase (Theta and Alpha) and high-frequency amplitude (Beta and Gamma). Theta-band power was also calculated as an additional measure of oscillatory activity associated with attentional processing. The resulting features were concatenated into a single feature vector where each row represented one EEG epoch labelled with an event, and each column represented either a PAC feature or a theta-power feature.
8. Machine Learning Classification: A Random Forest classifier was trained using the combined PAC and theta-power feature matrix to classify task-related cognitive conditions. The model learned relationships between oscillatory coupling patterns, spectral power measures, and behavioural outcomes observed during the Sustained Attention to Response Task (SART). 

Results:
The Random Forest classifier achieved an Area Under the Receiver Operating Characteristic Curve (ROC-AUC) of 0.86, indicating strong discrimination between the target cognitive conditions (missed target and correct non-target trials). An AUC value of 0.86 suggests that the model was able to reliably distinguish between classes using features derived from EEG activity. Statistical analysis of the extracted Phase-Amplitude Coupling (PAC) features revealed a p-value of 0.04, indicating a statistically significant difference between conditions at the α = 0.05 significance level. This finding suggests that the observed differences in neural oscillatory coupling were unlikely to have occurred by chance. Together, these results demonstrate that PAC-based EEG features, combined with theta-band power measurements, contain meaningful information related to attentional performance and can be leveraged for machine learning-based cognitive state classification.

Potential Applications:
The results of this project suggest that Phase-Amplitude Coupling (PAC) may serve as a useful EEG-based biomarker of attentional performance and cognitive state. By identifying neural patterns associated with changes in attention, PAC-based features could contribute to the development of non-invasive cognitive monitoring systems. Potential applications include early detection and monitoring of cognitive decline and neurological disorders, and real-time attention and fatigue monitoring in safety-critical environments.
